# FDE 工作原则手册（docs/FDE-Principle/）

编制日期：2026-10-03。本手册回答一个问题：**一名专业 FDE 在项目全生命周期的每个子阶段，应该遵守什么原则、用什么经验、避什么坑。**

## 来源与可信度分级

每条原则末尾带来源标记，三档可信度：

| 标记 | 含义 | 例子 |
|---|---|---|
| `[课程]` | 极客时间《FDE 实战课》沉淀的 SOP（`knowledge/` 目录，内部已核验整理） | 35 条原则、双向筛选八问 |
| `[外部·已核验]` | 本项目团队读过原文的外部公开资料（编号见 `docs/research/资料目录.md` 与 `source-catalog.json`） | 微软 D12、First Round P23、Baseten P17-19、Palantir P14、Bain D16/17、GOV.UK D01、GAPS A03 |
| `[外部·未核验]`/`[口述]` | 只有二手报道摘要、或用户/业内口述，尚未读到原文 | OpenAI FDE 团队报道、Palantir「多方案+trade-offs」口述原则 |

## 手册结构（项目前占比最大——本产品服务售前）

```
项目前（售前，本产品主战场，≈60% 篇幅）
 ├─ 01 获客与双向筛选   —— 值不值得谈、能不能进场
 ├─ 02 诊断访谈与真问题挖掘 —— 怎么问、怎么挖、怎么确认（最核心）
 └─ 03 方案呈现与商务交接  —— 多方案trade-offs、敢说不、合同与交接卡
项目中
 └─ 04 交付迭代与上生产  —— 每周demo、施工三问、评估驱动、上生产检查
项目后
 └─ 05 交接沉淀与复利    —— 自治阶梯、结项清单、复盘、止损退出
全程
 └─ 06 踩坑手册          —— 六大失败模式、中国六大坑、行业红线速查
```

## 这份手册和 FDE-Agent 产品的关系

三条使用路径：

1. **Agent 行为约束**：`02`/`03` 中的访谈纪律（中性提问、数字带口径、竞争假设、needs_evidence）即 Agent 状态机与 prompt 的行为规范来源。
2. **评测题来源**：违反本手册原则的情境 = 方案A（`docs/benchmarks/`）的对抗题与错误分类蓝本（如「过度转介」对应违反 03 的敢说不原则）。
3. **人的培训材料**：交接给人类专家复核时，本手册是判断「Agent 做得对不对」的共同基准。

## 阅读顺序建议

新人/新场景从 `06`（坑）开始建立风险意识 → `01`（筛）→ `02`（问）→ `03`（收口）。老手直接按子阶段查表。每篇内部按「子阶段 → 原则表 → 展开重点」组织，可当 checklist 用。
